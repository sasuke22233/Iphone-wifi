# Раздача Wi-Fi с VPN (iPhone)

Особенность Aura VPN — возможность раздать интернет с iPhone так, чтобы
подключённые устройства шли **через VPN-туннель**. iOS не позволяет
приложениям программно создавать точку доступа, поэтому работает связка:

```
Устройство (ноутбук/ТВ/телефон)
   │  Wi-Fi (Личная точка доступа iPhone)
   ▼
iPhone (Aura VPN)
   │  SOCKS5-прокси 0.0.0.0:10809 (общий)
   ▼
Xray-core → VPN-сервер → интернет
```

## Способ 1 — Общий VPN-прокси (гарантированно работает)

1. Откройте Aura VPN, подключите VPN (выберите сервер, нажмите кнопку).
2. Вкладка **«Wi-Fi»** → включите **«Раздавать прокси по Wi-Fi»**.
3. На iPhone включите **«Личная точку доступа»**
   (Настройки → Сотовая связь → Личная точка доступа).
4. Подключите ноутбук/ТВ к Wi-Fi-сети iPhone.
5. На подключённом устройстве укажите **SOCKS5-прокси**:
   - адрес: `172.20.10.1` (адрес iPhone на точке доступа; точное значение
     показано на экране «Wi-Fi» и зашито в QR-код);
   - порт: `10809` (или ваш в настройках);
   - логин/пароль — если включили «Защитить паролем».

### Куда вводить прокси на устройствах

| Устройство | Где настроить |
|---|---|
| iPhone/iPad | Настройки → Wi-Fi → (i) у сети → Настройка прокси → Вручную |
| Android | Настройки → Wi-Fi → сеть → Изменить → Дополнительно → Прокси → Ручной |
| Windows | Параметры → Сеть и Интернет → Прокси-сервер (SOCKS5 вручную/через PAC) |
| macOS | Системные настройки → Сеть → Дополнительно → Прокси → SOCKS |
| Linux | `export ALL_PROXY=socks5://172.20.10.1:10809` |
| Smart TV | Часто нельзя — используйте способ 2 или прокси на роутере |

QR-код на экране «Wi-Fi» содержит готовую строку `socks5://…` — удобно
перенести настройки вторым телефоном.

### Рекомендации
- Включите **«Защитить паролем»** — открытый прокси на точке доступа
  доступен всем, кто подключён к вашей сети.
- Порт 10808 на iPhone также доступен как **HTTP-прокси** (браузеры/ТВ).
- При смене сервера/настроек раздачи туннель переподключается автоматически.

## Способ 2 — Личная точка доступа + `includeAllNetworks`

В Aura VPN по умолчанию включён режим **«Захватывать весь трафик»**
(`includeAllNetworks = true` + `enforceRoutes = true`): система пытается
провести через VPN весь трафик устройства, включая раздаваемый по
«Личной точке доступа».

**Честно об ограничениях iOS:**

- Apple не даёт приложениям создавать точку доступа — используется
  системная «Личная точка доступа»;
- политика маршрутизации трафика точки доступа контролируется iOS и
  **может отличаться** между версиями прошивок и моделями;
- на практике на большинстве современных iPhone (iOS 15–18) трафик
  подключённых устройств идёт через VPN, если включён `includeAllNetworks`;
- если вы видите, что трафик подключённых устройств идёт мимо VPN —
  используйте **Способ 1** (общий прокси): он работает всегда.

## Полезные опции

| Опция | Где | Зачем |
|---|---|---|
| Захватывать весь трафик | Wi-Fi / Настройки | Трафик точки доступа через VPN |
| Исключить локальную сеть | Wi-Fi / Настройки | Доступ к роутеру, принтерам, Chromecast |
| Порт общего прокси | Настройки → Раздача | Если 10809 занят |
| Логин/пароль прокси | Настройки → Раздача | Доступ только у ваших устройств |

## Диагностика

- **Устройства не подключаются к прокси** — проверьте, что VPN подключён,
  раздача включена, адрес/порт совпадают с экраном «Wi-Fi».
- **Прокси есть, но сайты не открываются** — на устройстве должен быть
  указан именно SOCKS5 (не HTTP), порт 10809; проверьте логин/пароль.
- **Скорость низкая** — трафик идёт в два прыжка (устройство → iPhone →
  VPN-сервер); это нормально для раздачи через телефон.
